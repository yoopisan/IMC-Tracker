
# IMC Tracker

## Descripción
IMC Tracker es un proyecto académico que consta de una aplicación web desarrollada en Java que permite
calcular el Índice de Masa Corporal de los usuarios y consultar
el historial de sus mediciones.

## Objetivo
Facilitar el seguimiento del IMC mediante una aplicación web
que almacene los registros de cada usuario y permita consultar
la información mediante servicios REST.
Desarrollar habilidades para la planeación, el desarrollo y la implementación de ciertas tecnologías en la creación de una aplicación web, como Servlets, bases de datos y servicios REST.

## Tecnologías
- Java
- Maven
- JSP
- Servlets
- Jakarta REST (JAX-RS)
- MySQL
- WildFly
- HTML, CSS y JavaScript

## Funcionalidades
- Registro de usuarios.
- Inicio de sesión.
- Validación de información.
- Cálculo del IMC.
- Historial de mediciones.
- Servicios REST.
- Respuestas JSON y XML.

## Arquitectura
MVC y Controller-Service-Repository.

## Ejecución
El proyecto se compila mediante Maven y se despliega
en el servidor de aplicaciones WildFly.
